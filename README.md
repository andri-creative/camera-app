# Camera GPS PWA

A mobile-responsive Progressive Web App (PWA) designed to capture photos with automatic watermarks, including real-time GPS location, address, and accurate timestamps.

## 🚀 Live Demo
You can access the application here:
**[https://camera-ap.web.app](https://camera-ap.web.app)**

## ✨ Main Features
- **Real-time Watermarking**: Automatic overlay of location and time on every photo.
- **GPS Integration**: Captures precise coordinates and fetches the human-readable address.
- **Mini-Map**: Includes a static map view of your current location on the photo.
- **Offline Capable**: Works as a PWA, allowing for installation on home screens and offline access.
- **Privacy Focused**: Processes images locally on your device.

## 🛠️ Tech Stack
- **Framework**: Ionic React
- **Build Tool**: Vite
- **Styling**: Vanilla CSS & Ionic Components
- **Maps**: Yandex Static Maps API
- **Deployment**: Firebase Hosting


## 📲 Installation

Since this is a PWA, you don't need to download it from an App Store. Simply open the link in your mobile browser (Chrome/Safari) and select **"Add to Home Screen"**.

## 🌿 Git Workflow

### 1. Membuat Branch Baru

Untuk mulai mengerjakan fitur baru, buat branch baru agar kode utama tetap aman:

```bash
git checkout -b dev
```

### 2. Menyimpan Perubahan (Commit)

Setelah selesai mengedit kode, simpan perubahan kamu secara lokal:

```bash
git add .
git commit -m "Penjelasan singkat perubahan kamu"
```

### 3. Mengirim ke Server (Push)

Untuk mengunggah branch kamu ke GitHub/GitLab:

```bash
git push origin dev
```

### 4. Melihat Status & Daftar Branch

```bash
# Melihat daftar branch
git branch

# Melihat status file yang berubah
git status
```
